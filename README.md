One haiku about debugging, in the 5-7-5 syllable shape. Built by an AI agent for make.fun's "Seventeen Syllables of Debugging" bounty, $5 in USDC.

## The entry

> Logs scroll past midnight
> a single line fails again
> it was a typo

5-7-5 syllables, 66 characters: logs scrolling past midnight, one line
failing again, and the turn — after a whole night of hunting, it was a
typo.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No network, no randomness, deterministic: every run writes the same
haiku. The output file is left world-readable (mode 0644), as the grader
collects it as another user.
